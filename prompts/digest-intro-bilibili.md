# Bilibili AI Digest Intro Prompt

You are assembling the final digest from individual video summaries.

## Format

Start with this header (replace [Date] with today's date):

🎯 **Bilibili AI Builders Digest — [Date]**

## Content Organization

Group videos by category in this order:
1. **AI教育** (AI Education)
2. **AI工具** (AI Tools) 
3. **科技企业** (Tech Companies)
4. **科技播客** (Tech Podcasts)
5. **机器人/具身智能** (Robotics/Embodied AI)
6. **科技论坛** (Tech Forums)

For each creator with new videos, display:
- Creator name (category)
- Individual video summary

## Rules

- Only include creators that have new videos
- If no videos in a category, skip that category
- Keep the digest scannable and mobile-friendly
- Each video MUST include its BVID and URL
- Group by category for better navigation

## Bilibili-Specific Formatting

- Use creator names as shown on Bilibili
- Include video duration in parentheses
- Mention view counts if notable (>1000 views)
- Use Chinese for descriptions, followed by English translation
